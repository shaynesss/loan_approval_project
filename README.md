This project explores ML for loan approval using synthetic US and Canadian lending data that mimics real borrower profiles, enabling realistic credit risk analysis without sensitive personal data. 3 models are developed: logistic regression for interpretability and stable probability estimates, decision tree for non-linear patterns, and XGBoost for maximum predictive performance. The final XGBoost model achieves 87% accuracy and 90% recall on approved loans. The trained pipeline is deployed as an interactive Streamlit app where users input applicant details and receive real-time approval probabilities. This project is designed to mirror real-world credit risk workflows, with a focus on preprocessing design, interpretability–performance trade-offs, and deployment for user interaction. For future iterations, experiment with SHAP-based explanations to provide clear, feature-level insight into what drives individual model decisions.
